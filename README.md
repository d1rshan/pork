# > pork

find and kill dev-server ports.

## install

```
npm i -g @d1rshan/pork
```

## usage

### interactive

```
pork                 full-screen list — ↑↓ move · k kill · r refresh · q quit
```

### commands

```
pork list [--json]   one-shot table
pork kill 3000       kill whatever's on :3000
pork kill -9 3000    same, but with intent
```
